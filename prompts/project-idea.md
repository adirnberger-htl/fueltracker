# Project Idea "Fuel Tracker"

## Overview

These are the use cases for the "Fuel Tracker".

### 1

When I am at a gas station I want the recording of my data to be as easy as possible and cause minimal delay to the process. 

### 2

I want to be able to track multiple cars and have support for electric and traditional diesel and super.

### 3

I want to be able to know if I'm driving in a fuel efficient manner.

### 4

I want to know when I'll need to fill the tank back up in the current car, how much it will cost me and how much money I will need to sacrifice each month to keep the car operational (considering only fuel for now).

### 5

I want to know which time is the cheapest to go fill up my tank and based upon that information I want a recommended next time to fill up my tank.
